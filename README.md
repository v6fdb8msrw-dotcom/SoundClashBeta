# Sound Clash

Partyspiel rund um Musik: Künstler blind ranken, Song gegen Song antreten lassen, Sieger küren.
Hörproben kommen kostenlos von Deezer, Spotify und YouTube sind als Suchlinks eingebunden.
Mitspieler können ihr Handy per QR-Code koppeln (abstimmen, eigenes Line-up, eigene Songs wählen).

**Spielen:** https://v6fdb8msrw-dotcom.github.io/SoundClashBeta/ – auf dem iPhone in Safari über
„Teilen → Zum Home-Bildschirm“ als App installieren. Spielstände bleiben nur auf dem jeweiligen Gerät;
im Dialog „Spielstand“ lassen sie sich als Datei (AirDrop) zwischen iPhone und Mac übertragen.

Technik: React, TypeScript, Vite, PWA. Details für die Weiterentwicklung stehen in `CLAUDE.md`,
die Spielregeln in `docs/MECHANIK.md`. Die ursprüngliche Ein-Datei-Fassung liegt in `legacy/index.html`.
